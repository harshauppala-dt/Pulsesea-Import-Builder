Samsung Import Builder

Pull a DispatchTrack route’s Samsung orders, enrich each one with its export details, and build one import payload per order from your template.

  1. Fetch route orders/fetch-samsung-orders
  2. Export each order/orders/api/export.xml
  3. Merge into templatedoList[0] + doItemList
  4. Downloadcombined JSON or ZIP
DispatchTrack

CORS proxy

Needed when DispatchTrack blocks direct browser calls. The proxy receives {url, method, headers, body} and returns {status, statusText, headers, body}.

Responses

Orders are matched by order number or DO number. Orders without a match are built from fetch data only.

 

Everything except doItemList is kept as written, for every order in the run.
